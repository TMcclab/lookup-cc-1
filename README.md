# Color Space Lookup & Delta E Tool

A client-side web application that calculates color difference ($\Delta E_{76}$) between a reference Lookup Table and TEST Colour samples, helping you find the closest matching colors.

## ⚠️ Notices & Disclaimers
* **Notice on Data Usage:** This tool performs color space analysis based on the data provided by the user. Please verify accuracy and suitability under your own responsibility.
* **Reference Data:** No proprietary reference database is included. All Lookup Tables must be provided by the user.
