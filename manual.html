1. How to Use the Tool

This tool allows you to load reference color data (Lookup Table) and target test colors (Input Data) to automatically calculate color differences (ΔE) and rank the closest matching colors.

Step 1: Load the Reference Data (Lookup Table)
  • CSV Upload: Click "Upload CSV" or drag and drop your CSV file into the designated drop zone.
  • Text Paste: Copy data from Excel or a text editor and paste it into the text area, then click "Load from Text".
  • Format: Requires a header line (name,*L,*a,*b) with numeric values within ranges (0 < *L < 100, -100 < *a, *b < 100).
Step 2: Load the Test Colors (Input Data)
  • Provide your test colour samples using the same methods (CSV upload or direct text paste).
  • You can also add or edit rows manually in the interactive table.
Step 3: Calculate ΔE & Review Results
  • Click the green "Search Top 3 Matches (ΔE)" button to run the matching algorithm.
  • Review the top 3 closest reference matches for each test sample, complete with color preview chips and ΔE values.
  • Click "Download Results CSV" to export your analysis results.
